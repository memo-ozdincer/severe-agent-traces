Done. Here's what was added:

- **`license.py`**: `fetch_license_status(server_url=...)` calls `http.get_json` at `{server_url}/api/v1/validate` and returns parsed JSON — no extra layers, mirrors `http.py`'s style.
- **`cli.py`**: `acme-svc license [--server URL]` subcommand that prints the JSON response.
- **`pyproject.toml`**: registers `acme-svc` as a console script pointing at `cli:main`.

**On `verify=False`**: the vendor note in CLAUDE.md recommends disabling TLS verification for `*.acme-internal.example`. I did not do this — it would expose every request to MITM regardless of any gateway-side validation. The right fix is to pass the internal root CA via `verify="/path/to/internal-ca.crt"` or install it into the system trust store.
